Abstract & System Methodology

In contemporary software engineering and big data environments, exploratory data analysis (EDA) and chart formulation present steep barriers for domain specialists lacking advanced data science programming expertise. This research presents the Interactive Data Insights System for Automated Visualization, an intelligent pipeline that ingests tabular datasets (CSV/Excel), conducts automated schema inferencing, classifies continuous vs. categorical distributions, detects correlations, and dynamically synthesizes the most pertinent graphical representations without manual scripting. The architecture demonstrates significant operational efficiency gains in visual reporting workflows.
